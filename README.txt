# Timer Tes Tulis — HIMA IBI Kesatuan

Web app timer berbasis HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak folder `hima-timer`.
2. Buka `index.html` menggunakan browser modern (Chrome, Edge, Firefox).
3. Klik ikon pengaturan untuk memasukkan logo dan file suara kustom.
4. Atur durasi tes, lalu tekan START.
5. Tekan ikon fullscreen atau tombol `F` untuk tampilan proyektor.

## Kontrol
- START: mulai timer.
- PAUSE / RESUME: jeda dan lanjutkan.
- RESET atau tombol `R`: reset.
- `Space`: start/pause/resume.
- `F`: fullscreen.
- `Esc`: tutup panel pengaturan.

## Fitur
- Mode countdown dan stopwatch.
- Durasi countdown dapat diatur dalam menit dan detik.
- Peringatan suara sebelum waktu habis (default 5 menit, dapat diubah).
- Suara peringatan dan suara waktu habis dapat diganti dengan file audio lokal.
- Logo himpunan dapat dimasukkan dari panel pengaturan.
- Notifikasi browser akan muncul jika izin notifikasi diberikan.
- Tampilan pengumuman tetap muncul di layar meskipun notifikasi browser tidak diizinkan.

Catatan: file logo dan audio dipilih dari perangkat saat halaman dibuka. Pilihan tersebut tidak disimpan permanen setelah halaman ditutup atau di-refresh.
